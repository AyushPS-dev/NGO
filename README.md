# 🌱 Green Roots — Plant Today, Breathe Tomorrow

**Green Roots** is a simple, responsive NGO website focused on tree plantation, plant care, and environmental awareness. The website encourages people to protect nature and contribute towards a greener and healthier planet.

## 🌿 About the Project

The main objective of this project is to create awareness about environmental conservation and encourage people to participate in activities such as tree plantation and plant care.

This project is developed as part of a college Mid-Semester Examination (MSE) using HTML, CSS, and basic JavaScript.

## ✨ Features

* **Home Page:** A welcoming landing page with a nature-themed background.
* **About Us:** Introduction to Green Roots and its mission.
* **Our Green Initiatives:** Information about tree plantation, plant care, and nature awareness.
* **Volunteer Form:** A form where visitors can enter their name, email, and preferred activity.
* **Contact Section:** Displays contact information.
* **Responsive Design:** Adapts the layout for desktop and mobile screens.
* **Interactive Elements:** Navigation links, button hover effects, and a JavaScript-powered form confirmation message.
* **Automatic Footer Year:** Displays the current year automatically.

## 🛠️ Technologies Used

* **HTML5** — Website structure and content.
* **CSS3** — Styling, layout, colours, and responsive design.
* **JavaScript** — Form interaction and automatic year display.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Ensure that `index.html`, `style.css`, and `script.js` are in the same folder.
4. Open `index.html` in your web browser.
5. Alternatively, use the Live Server extension in VS Code to run the website locally.

## 🌍 Website Sections

1. **Home** — Introduces Green Roots and its environmental mission.
2. **About Us** — Explains the purpose of the initiative.
3. **Our Work** — Highlights tree plantation, plant care, and nature awareness.
4. **Volunteer** — Allows visitors to fill out a volunteer interest form.
5. **Contact** — Displays contact information.

## ⚙️ JavaScript Functionality

The project uses basic JavaScript to:

* Display the current year in the footer.
* Handle the volunteer form's submit event.
* Prevent the page from reloading when the form is submitted.
* Display a thank-you message using the visitor's name.
* Reset the form after submission.

**Note:** The volunteer form is currently a frontend demonstration. It does not store user information in a database or send it to a server.
